# Changelog

## 0.5.4

- The mod's author is now watdafawx (it was mikey).

## 0.5.3

- New mod icon: a 3x3 grid of Botany Pots, based on the Botany Pots logo.

## 0.5.2

- Added Botany Pots crops for 29 more Mystical Overgrowth seeds (antimony, bauxite, titanium, tungsten, time crystal, spawner, shulker and more).
- Added support for Roost chicken food seeds, tiers 1 to 9.
- Hoppers and pipes can now only pull from a Garden's output slots. They can no longer insert items or take seeds, soil, pots, tools or upgrades out.
- Cells pause growing (and stop using FE) while the output bank is full, then resume as soon as a slot frees up. Nothing is lost.
- Fixed Power Pot cells using FE with nothing planted.
- FE per tick usage now shows in the GUI and the Jade tooltip, and Jade shows each cell's seed name.
- Added a common config file (`config/botanygardens-common.toml`).
- Renamed the mod from Garden Pots to Botany Gardens.
